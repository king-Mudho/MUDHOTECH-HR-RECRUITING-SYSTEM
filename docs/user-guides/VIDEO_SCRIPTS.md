# Video script outlines

Short screen recordings (2–4 minutes each) to record on staging once it is live (owner follow-up).
Use the demo organisation and synthetic candidates only; never real people's data.

| # | Audience | Title | Outline |
|---|---|---|---|
| 1 | Candidates | Applying for a job | Find a vacancy → create account → upload CV → check what was read → answer questions → submit → track status |
| 2 | Candidates | Interviews and offers | Choose an interview time → add to calendar → read the offer → accept with your typed name |
| 3 | Candidates | Your privacy | How we use AI → request your data → talent pool opt-in/out → SMS/WhatsApp opt-in and STOP |
| 4 | Recruiters | Creating a vacancy | Details → criteria with evidence and justifications → questionnaire (prohibited-question check) → submit for approval |
| 5 | Recruiters | Reviewing applications | Filters and bands → evidence per criterion → verify a claim → ask a clarification → blind review |
| 6 | Recruiters / HR | Shortlist and approval | Propose shortlist with reasons → HR approval → notification delay and undo → nobody else told |
| 7 | Recruiters | Interviews and scorecards | Schedule with proposed times → panel → independent scorecards → consolidated feedback |
| 8 | HR managers | Offers and close-out | Offer approval chain → issue → acceptance → record hire → close vacancy → confirmed close-out |
| 9 | HR managers | Reports and exports | Filters → funnel and timings → AI agreement and rubric-review alerts → blind export |
| 10 | Org admins | Setting up your organisation | Profile → team and roles → policies (AI, dual control, notification delay, SSO) → privacy notice |
| 11 | Org admins | Plan, billing and integrations | Usage and limits → pay an invoice with EcoCash → connect calendars → webhooks and API keys |
| 12 | Auditors | Reconstructing a decision | Audit log → reconstruct an application → export PDF |

Each video: 10-second intro (who it is for), the task in real time, one "good practice" tip, and where
to find help (user guides, support email). Add captions; keep the language plain.
